# Dataset: Personal Loan Modeling

## Overview
This project uses the **Personal Loan Modeling** dataset sourced from Kaggle.

- **Dataset Name:** Personal Loan Modeling
- **Source:** Kaggle ([Personal Loan Modeling Dataset](https://www.kaggle.com/datasets/teertha/personal-loan-modeling))
- **Total Records:** 5,000 customer records
- **Input Features:** 12 attributes

## Target Variable
- **Target Column:** `Personal Loan`
- **Values:**
  - `0`: Did not accept personal loan
  - `1`: Accepted personal loan
- **Class Distribution:** Highly imbalanced (~90% negative / ~10% positive class rate)

## Input Features
1. **Age:** Customer's age in completed years
2. **Experience:** Years of professional experience
3. **Income:** Annual income of the customer ($000)
4. **ZIP Code:** Home address ZIP code
5. **Family:** Family size of the customer
6. **CCAvg:** Average spending on credit cards per month ($000)
7. **Education:** Education level (1: Undergrad; 2: Graduate; 3: Advanced/Professional)
8. **Mortgage:** Value of house mortgage if any ($000)
9. **Securities Account:** Does the customer have a securities account with the bank? (0/1)
10. **CD Account:** Does the customer have a certificate of deposit (CD) account with the bank? (0/1)
11. **Online:** Does the customer use internet banking facilities? (0/1)
12. **CreditCard:** Does the customer use a credit card issued by this bank? (0/1)

> **Note:** The actual dataset file (`Bank_Personal_Loan_Modelling.csv` / raw data) should **not** be committed to GitHub yet.
